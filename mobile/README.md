# RHM Flutter Android client

This folder contains the Flutter client, its Dart tests, Android build templates and the API client for the existing RHM FastAPI service.

- Current package version: `0.1.10+11`.
- Minimum SDK constraints: Dart 3.13+, Flutter 3.47+.
- The Android Gradle project is generated by `../scripts/prepare_android_project.sh`; generated build output is ignored.
- The client stores its server URL and bearer token locally using Android secure storage. It does not contain provider API keys or the Python backend.
- Android voice recognition and text-to-speech depend on services and language packs installed on the device.

Read the repository-level README and `docs/` before changing API routes, update behavior, signing, or runtime architecture.
